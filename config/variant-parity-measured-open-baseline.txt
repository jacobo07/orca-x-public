# Capabilities that have been measured, whose gap is named, and that nobody is blocked on.
#
# Distinct from variant-parity-unknown-baseline.txt on purpose. A name there means nobody has
# looked yet; a name here means someone looked, wrote down what the current and target states are,
# and the work is simply not done. The two need different next actions -- investigate, versus
# implement -- and a single "unknown" bucket could not say which.
#
# This list may only SHRINK, in both directions, exactly like the unknown list: an entry in the
# manifest with disposition "measured-open" that is not named here fails the gate, and a name here
# that is no longer measured-open fails as a stale exception.
#
# Moving a capability from the unknown list to this one is progress in knowledge and NOT progress
# toward shipping. The gate reports one unresolved total across both lists precisely so that move
# cannot make the number look better. An id may appear in one list or the other, never both.
#
# Two entries arrived from the unknown list on 2026-09-08, carrying the measurements already
# written into their notes. session.lifecycle-vocabulary left again the same day, CLOSED rather
# than relabelled -- the runtime now retains the failed-resume fact and projects it, and mobile
# reads it three-valued against a negotiated capability. That is the unresolved total genuinely
# falling by one, which is the only way it is allowed to fall.
#
# What remains is the destructive one: a git operation a client can issue against a file it last
# saw some time ago.
