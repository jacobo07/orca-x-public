Status semantics

The canonical reference for what Orca's state colours mean. Rendered from the live tokens in main.css — this is not a mockup of the system, it is the system. The rules are in docs/STYLEGUIDE.md; the machine-checked list is config/status-semantics.jsonc.

Two channels

Interaction is what the user is doing to a row. System is what the row is doing on its own. A row can be selected and failing, so the two must never share a colour — green-for-selected and blue-for-healthy are the same defect in opposite directions.

System states

Healthy
--status-success
Observed to be working — a positive reading, not the absence of a bad one.
Not for: a selected row · a default with nothing behind it
current · durable · synced
Pressured
--status-warning
Working, and closer to a limit than it should be. A warning about the future.
Not for: a failure · decoration · a highlight
degraded · throttled · low headroom
Critical
--status-error
Ended badly, or failing now. A report about the present.
Not for: a button the user is about to press — that is --destructive
failed · conflict · revoked
Unknown
--status-unknown
Not measured, not reachable, or inconclusive. An epistemic state, never a verdict about the system. Its mark is hollow where every other state is filled.
Not for: healthy · offline · disabled · idle · zero · not applicable
unmeasured · unreachable · inconclusive
Needs approval
--agent-question
An agent is waiting on a human answer. A request addressed to the user.
Not for: a warning · a failure
waiting · permission
Idle
--muted-foreground
Nothing is happening and nothing is wrong. The resting state.
Not for: unknown · offline · failed
dormant · parked · not running

Interaction

Selected
--ring / --accent
The row the user is acting on, and the focus indicator.
Not for: healthy · current · durable · any system verdict
hover · focus · current

The pairs that get confused

Selected vs Healthy

Selected Healthy

Different channels. Selection says you pointed at this; health says it is well.

Dormant vs Offline

Dormant Offline

Both Idle, distinguished by the word. Dormant is a release we chose; offline is a peer not answering and we know it. If we do not know, it is Unknown.

Pressured vs Critical

Pressured Critical

Still serving, or not.

Stale vs Unknown

Stale · 4h Unknown

Stale means we hold a reading and it is old — show the age. Unknown means we hold no reading at all.

Blocked vs Needs approval

Blocked Needs approval

Blocked is a system condition. Needs approval is a request addressed to the user.

Durable vs Synced

Durable Synced

Both Healthy. The difference is the label, never the colour — a rainbow is not a semantic system.
