## Protocol (19-VERIFICATION, restore by byte copy)

Driver `g04-mutant.ps1` plus the drill table `g04-drills.ps1`, both in the job tmp directory
`C:\Users\<owner>\.claude\jobs\fd0cc958\tmp\`, never in the repo. Per drill:

1. `git diff --quiet -- src config mobile` exit 0; the target's bytes are copied to the tmp directory and their
   sha256 recorded.
2. The anchor's full text occurs exactly once (`[regex]::Matches` count 1). A multi-line anchor is written with the
   file's own newline (CRLF or LF, detected per file). For P20-G2 the anchor is the span from
   `,<NL>  "hostCapabilities": {` up to the file's last `<NL>}`, also counted once.
3. Plant by that single replacement (same encoding, BOM preserved if present). PLANT_CONFIRMED means
   `git diff --name-only` names only that file, the plant is present and the diff stat matches the plant.
4. Catchers: `pnpm.cmd exec vitest run --config config/vitest.config.ts <file>` or `pnpm.cmd run check:host-card-claims`.
   CAUGHT means every named catcher exits non-zero with the expected row or gate line.
5. Restore in a `finally` block by copying the saved bytes back (not `git checkout`). RESTORE_VERIFIED means the
   sha256 equals the pre-plant hash, `git diff --quiet -- <file>` exits 0, every catcher exits 0 again and
   `git diff --quiet -- src config mobile` exits 0.
