## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session broker answers -> card render | evidence decides whether a control exists |
| broker stage records -> card copy | broker-written stages become words a person reads |
| target status answer -> host-announced | the only evidence that the host itself answered |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-16 | Spoofing | wrong-host wake from a card whose host is not the bound target | high | mitigate | showControl only from composeHostWakeRoute send; render rows for unbound and awake |
| T-21-17 | Spoofing | ambiguous broker draws a control | high | mitigate | ambiguous route gives no control and a labelled state |
| T-21-18 | Spoofing | Woken or ready rendered from a broker stage, or host-announced faked by clock skew | high | mitigate | observer rule in the gate; rebasing to repliedAt; pre-press answers excluded |
| T-21-19 | Repudiation | a button without a backend effect | high | mitigate | host-card-wake classified effect host.wake.request; per-control scope (21-03) |
| T-21-20 | Information disclosure | MAC reaches the card | medium | mitigate | the card sees targetId and label at most, through props; 21-01 keeps the MAC off the wire |
</threat_model>
