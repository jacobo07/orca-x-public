<objective>
Ship the Windows logon Scheduled Task for the Host Service as `orca serve autostart install|remove|status`
(D-06, D-08), and make the autostart launch treat "lock held by a live Orca" as satisfied (D-07) so
RestartOnFailure never loops while the desktop or a serve already runs.

Purpose: the brief's decision 1. The machine, not the UI, keeps the host available after logon.
Output: pure XML builder, a schtasks/PowerShell runner behind an injectable exec, CLI verbs, exit-code mapping.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> Task Scheduler | the CLI writes a persistent logon effect for the current user |
| SSH relay bridge -> host CLI | a remote shell's `orca` runs on the Orca host |
| temp XML file -> schtasks.exe | file read by another process after we write it |
