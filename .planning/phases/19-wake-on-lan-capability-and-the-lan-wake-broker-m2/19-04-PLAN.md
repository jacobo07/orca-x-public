<objective>
Give the Owner a local way to register wake targets and issue REMOTE_WAKE grants on the broker: `orca wake target
add|remove|list` and `orca wake grant add|remove|list`, backed by local-only `host.wake.admin.*` methods.

Purpose: SC2 administration. D-05 (targets live only on the broker, registered locally by the Owner; phones see ids),
D-07 (issuing a grant is a local Owner act; no phone-side grant surface), D-10 (one writer: the running broker, so a
CLI edit cannot race the revoke purge and resurrect a grant).
Output: admin methods, CLI specs and handlers, handler-group registration, the shared local-invocation guard.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI on the broker host -> runtime (local transport) | The Owner's act; trusted only when truly local |
| SSH relay bridge -> CLI | A remote shell that reaches the runtime as a local caller |
| runtime-scope paired device -> admin methods | Bypasses the mobile allowlist; must be refused by the method itself |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-18 | Elevation of privilege | host.wake.admin.* from a paired device | critical | mitigate | isLocalRpcCaller refusal on every admin method (Tasks 1-2; mutant P19-M5 in 19-05) |
| T-19-19 | Elevation of privilege | `orca wake` through the SSH relay | high | mitigate | assertLocalInvocation before any call (Task 3) |
| T-19-20 | Tampering | malformed MAC / broadcast / port | medium | mitigate | Validated at the CLI and in the zod schema (Task 1) |
| T-19-21 | Elevation of privilege | grant for a revoked or unknown device | high | mitigate | deviceExists check at grant time and authority at the effect (Task 2) |
| T-19-22 | Tampering | CLI and revoke purge racing on the state file | medium | mitigate | The CLI never writes the file; the running broker is the single writer (D-10) |
| T-19-23 | Information disclosure | MAC in non-admin output | low | mitigate | MACs only in local target rows; grant rows and phone methods carry none (Task 2) |
